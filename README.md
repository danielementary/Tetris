# Tetris

## Description
High school project : from scratch tetris implementation in Python and TKinter.

## Retroflag GPi Case 2
This branch adapts the game to run on the [Retroflag GPi Case 2](https://www.retroflag.com/GPi-CASE-2.html) handheld: fullscreen at the screen's resolution, controls remapped to the built-in gamepad (read through `evdev`), plus counter-clockwise rotation and bug fixes. See `master` for the original version.
